# Инструменты без подключения к плате

Запускайте из корня репозитория:

```sh
python tools/offline.py --help
python tools/offline.py compare-traces --help
python tools/run_tests.py --help
```

`offline.py` передаёт аргументы существующему скрипту и использует корень как рабочую папку. Он не меняет формулы, входы, pin-проверки или формат отчёта. Доступны анализ стабильности, диагностика fidelity, экспорт/сравнение выходов, упаковка сводки, карта ёмкости и независимые аудиты fresh/no-BL8. Эти инструменты читают сохранённые данные; acquisition-сценариев в этом списке нет.

Сами скрипты пока остаются в корне: их имена, расположение и SHA входят в ранее опубликованные аудиты. Старые команды `python analyze_fresh_stability.py ...` продолжают работать. Это совместимость исторических протоколов, а не новое место для произвольных утилит.

Новые независимые служебные программы размещайте здесь. Новую аппаратную логику подключайте явно через корневой `experiment.py` после review. Полное описание офлайн-команд — в [документации](../docs/README.md), порядок проверки — в [tests](../tests/README.md).
