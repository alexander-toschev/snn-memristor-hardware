# Структура и совместимость исторических опытов

Организация обновлена 17 октября 2026. Корневой `experiment.py` остаётся единой точкой входа для acquisition. Документация распределена по `guides/`, `protocols/`, `plans/`, `reviews/`; тесты — в `tests/`, служебные входы — в `tools/`. Соответствие старых и новых документов записано в [layout.json](layout.json).

## Почему часть Python-файлов остаётся в корне

Collect-и audit-сценарии проверяют SHA зависимостей и используют имена файлов как часть provenance. Перенос таких модулей потребовал бы изменения frozen протоколов или подмены исторических проверок. Поэтому acquisition, converters, аудиторы, численные helpers и существующие offline-скрипты оставлены по прежним путям, с прежними байтами. `tools/offline.py` только запускает их обычным отдельным Python-процессом из корня; он не загружает драйверы и не обходит проверки.

Три root-теста упоминаются в frozen аудиторах и сохранены неизменными. Остальные тесты перенесены, их пути к repo-root и импорты общих FakeConnector обновлены; численные допуски и протоколы не менялись. Старые команды тестов из журналов относятся к указанному в них commit. Текущий полный запуск — `python tools/run_tests.py`.

## Неизменяемые данные

`weights/`, `configs/`, `results/`, `reports/`, `vendor/`, старые manifest и raw не редактировались ради структуры или ссылок. Ссылки из исторических отчётов продолжают открываться через небольшие корневые указатели там, где это необходимо. Документы в новых папках ссылаются на актуальные относительные пути. Для воспроизведения самого исторического кода нужен его recorded Git commit.

`.tmp/` теперь игнорируется в корне; содержимое не удаляется. Private-драйверы, секреты, `.venv`, `.deps` и `.tools` сохраняют прежние правила. Никакие локальные private-заметки из `.tmp` не переносились в документацию.

## Новые материалы

- Новый протокол документировать в `docs/protocols/`, будущие планы — в `docs/plans/`.
- Инструкции — в `docs/guides/`, исторические review — в `docs/reviews/`.
- Отчёт разработчику по дате — `docs/developer-reports/YYYY-MM-DD/`.
- Новые самостоятельные offline-утилиты — в `tools/`, тесты — в `tests/`.
- Не переносить frozen source и не обновлять старые manifest SHA только ради новой структуры.
