# Финальная проверка полного MNIST STDP

**Актуальный статус:** исходная локальная сессия
`7a536bf8-0269-4edd-b454-a8ba2c33c219` остановлена после head epoch5 и остаётся
partial. Команда ниже со старым UUID сохранена как описание исходного
completed-only контракта, **сейчас её не выполнять как финальный full audit**.
Отдельный локальный recovery готовится `python_refactor` и проверяется
validator; его UUID/команда/аудитор должны быть закреплены отдельно.
Partial-данные и исходники не переписываются, финальной test accuracy пока нет.
Обучение, признаки и тяжёлая обработка остаются локальными, не переносятся на Pi.

Новый проверяющий код: `tools/audit_mnist_stdp_full.py`. Старые smoke-аудиторы
жёстко проверяют 128 примеров и не подходят для полного результата.
Ниже команды из корня репозитория. Выполнять основной аудит только после
завершения процесса и появления `manifest.json` со статусом `completed`.
Незавершённый прогон не считается полным результатом; аудитор его отклонит.

Проверка маленьких синтетических примеров, без обучения и вызова сети:

```powershell
& .venv-mnist-pilot/Scripts/python.exe -B -m unittest tests.test_mnist_stdp_full_audit -v
```

Финальный CPU-аудит сохранённых файлов текущего полного запуска:

```powershell
& .venv-mnist-pilot/Scripts/python.exe -B tools/audit_mnist_stdp_full.py --session results/mnist_stdp_retraining_20261019/7a536bf8-0269-4edd-b454-a8ba2c33c219 --output reports/2026-10-19/mnist-stdp-training-review/FULL_SAVED_EVIDENCE_AUDIT.json
```

Выход создаётся исключительно новым файлом. Уже существующий отчёт не
перезаписывается. Аудитор требует отдельную закреплённую среду MNIST;
системные пакеты и исполняемые среды других экспериментов не меняются.
Проверка читает примерно 6 ГБ сохранённых признаков несколько раз и
пересчитывает train-only scaler на CPU блоками по 128 строк. Время пока
не измерено. GPU, BindsNET, Connector, SNN и оптимизатор не запускаются.
Сохранённый линейный readout пересчитывается на CPU: исходная float32
предобработка, затем float64 матричное произведение. Заранее фиксированы
допуски logits atol=1e-3, rtol=1e-4. Любое превышение или несовпадение argmax
даёт `review_required` и exit3; отчёт сохраняет разницы и margins. Даже
несовпадение почти равных logits внутри допуска не считается автоматическим PASS.

## Что должно быть подтверждено

| Этап | Фактическое свидетельство |
|---|---|
| STDP | Ровно train ID 0…29999, 100 шагов на каждый; 3 000 000 шагов. SHA каждой конечной матрицы, clipping первого шага отдельно от последующих изменений. |
| Признаки train | 235 последовательных блоков, последний 48 строк; ровно 30 000 строк × 36 864 признака. Все используют новые обученные веса и неизменные пороги/bias. |
| Scaler | Только train: float32 log1p, потоковая float64 выборочная дисперсия, результат float32, минимум SD 1e-6. Точный CPU replay сохранённых mean/SD. |
| Readout | 25 эпох; каждая перестановка содержит все 30 000 train ID ровно один раз; 59 обновлений/эпоху, всего 1475. Выбран последний epoch25. |
| До test | SHA readout, scaler и нового checkpoint зафиксированы до первого test-признака и совпадают с конечными файлами. |
| Признаки test | 79 последовательных блоков, последний 16 строк; ровно 10 000 строк. Метки обоих split совпадают с закреплёнными официальными IDX. |
| Результат | Одно событие test после обучения/freeze. Accuracy и confusion пересчитываются из сохранённых logits и официальных меток; argmax имеет обычное разрешение равенств по первому индексу. |

`planned` — параметры из preflight, а не свидетельство исполнения.
`confirmed_execution` проверяется по строгой последовательности событий:
30000 train, 235/79 feature batches, 30000/10000 feature rows, 25 epochs,
1475 updates по последней завершённой эпохе, одна test evaluation.
События подтверждают завершённые этапы, но не заменяют независимое повторное
выполнение каждого шага нейронной сети или оптимизатора.

## Границы результата

Это восстановление архивного **модельного STDP MNIST** с новой инициализацией
и закреплённой средой; не аппаратный мемристорный STDP и не обещание 69,65%.
Код проверки не переисполняет BindsNET/STDP, encoder или optimizer;
он проверяет сохранённые значения, CPU linear readout, связность артефактов,
события и закреплённые исполнявшиеся исходники. Только первый train image
имеет запись весов после каждого шага, остальные — после каждого изображения.
По таким записям нельзя отдельно восстановить каждый LTD/LTP event.

Перед принятием результата требуется независимое ревью самого аудитора,
затем проверка его отчёта независимым агентом. Изменять выполняющийся
experiment.py, run_full.py, зависимости или исторические данные запрещено.
