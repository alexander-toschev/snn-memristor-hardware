# Зафиксированные проблемы ячеек MemriBoard

[Карта всех 256 ячеек](index.html) · [Таблица CSV](CELLS.csv) · [Проблемы и подтверждающие данные JSON](PROBLEMS.json)

Только наблюдавшиеся проблемы в сохранённых аппаратных результатах проекта. Без хронологии, успешных проверок и рейтинга исправности. Координаты WL0–WL7 × BL0–BL31. Один адрес может иметь несколько разных замечаний. Наблюдения относятся к проверенным режимам и состояниям; они не доказывают постоянный дефект ячейки.

## Что установлено

- В адресной диагностике mode10 нулевой отклик зафиксирован у **160 ячеек**, включая все **120 ячеек BL16–BL30**. На 14 выбранных адресах mode9 давал ненулевой отклик. Точная причина различия трактов не установлена.
- Запись: встречаются недостигнутые цели G, исчерпание лимита SET/RESET и перескок интервала.
- Стабильность: встречаются дрейф после других операций/выдержки, изменение повторно полученных уровней и разброс чтений.
- MVM: зафиксированы слабый/неразличимый отклик, недостаточный воспроизводимый диапазон, нелинейность и несовпадение проверочного отклика с предсказанием.
- Отказы пар и групп выделены отдельно. По такому результату нельзя установить, какая именно ячейка виновата.

## Обозначения

| Код | Смысл |
| --- | --- |
| G | Недостижение цели, перескок или исчерпание бюджета записи |
| Z | Нулевой/слабый отклик или недостаточный диапазон |
| D | Дрейф или несогласованность между циклами |
| N | Разброс чтений; CV неопределён либо превышает порог |
| L | Нелинейность либо ошибка предсказания/суммирования |
| I | Ограничение воздействия токовым guard, если зафиксировано |
| Q | Итоговый проверочный критерий не подтверждён; причина не локализована |

Источник — сохранённые поадресные критерии и диагностические отчёты, а не новый полный разбор всех сырых ADC. Общие ошибки эксперимента без адресной локализации не приписаны всем ячейкам. Числа разных режимов не суммируются. В карточке приведён пример измерения для каждого подтверждающего семейства; путь и JSON pointer/номер строки позволяют проверить его.
