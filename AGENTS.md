# Правила работы с платой

- Любое аппаратное взаимодействие допускается только через публичные методы
  штатного `manager.board.Connector`: `open_port()`, `impact()`, `close_port()`.
- Запрещены прямые GPIO/SPI/FPGA-вызовы, импорт и вызов физического драйвера
  из кода эксперимента, доступ к `Connector.interface`, обходы Connector,
  собственные драйверы и неявные сканирования через вспомогательные классы.
  Подключаемый драйвер выбирает и вызывает сам штатный Connector.
- Сейчас пользователь запретил любые физические запуски. Допустимы обновление
  кода, offline tests и --dry-run без подключения. Прежнее разрешение на
  CIFAR эксперимент историческое; новый запуск требуют явного разрешения.
  Согласованный протокол: native-импульс неизвестной длительности, один массив
  32×8 с последовательными плитками. Не заявлять 125 мкс или два кроссбара.
- По умолчанию использовать simulator. Физические сценарии `read_all.py` и `experiment.py`
  требуют явного `--run-hardware`; без флага подключение запрещено.
- Сохранять исходные ADC, команды, ответы, ошибки и provenance. Не заменять
  невалидные измерения ограниченными или выдуманными значениями. Модельные
  оценки сопротивления и результаты симулятора не выдавать за калибровку платы.
