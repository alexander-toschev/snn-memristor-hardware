Как читать проверки

SNR = (μV−μ0) / max(1 ADC, √(SDV²+SD0²)); SD выборочное. CV = √(SDH²+SD0²)/(μH−μ0), только при положительном знаменателе. ε = μH−2μL+μ0; SEε = √(SDH²/5+4SDL²/5+SD0²/5). Допуск ε = max(5%|μH−μ0|, 3SEε, 2 ADC). ΔG = Gpost−Gpre; SEΔ = √(SDpre²/3+SDpost²/3), допуск доли = max(5%,3SEΔ/Gpre). Фактические значения критериев этой сессии сохранены в criteria.json и provenance.json.

Отрицательный ε означает суб-линейный, положительный — супер-линейный двухуровневый отклик; это описание измерения, не установленная причина. Общий zero для WL учитывается в шуме, но не делает оценки разных ячеек независимыми. Показанные числа округлены для чтения до 12 значащих цифр; CSV сохраняет числовую точность JSON.
