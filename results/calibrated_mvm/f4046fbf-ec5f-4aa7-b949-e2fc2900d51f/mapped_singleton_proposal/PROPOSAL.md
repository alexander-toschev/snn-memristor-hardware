# Предварительная раздельная адресация BL для WL-пар

Исходные устойчивые одиночные отклики: 102.
Вместимость без проверки разности: 49 позиций / 98 ячеек.
Разрешимые текущие разности по basis+selection с консервативным SD: 47 позиций / 94 ячеек.

Это post-hoc предложение, не подтверждённая программируемость и не новая квалификация. Неиспользованная ячейка не объявляется неисправной.

Каждый вклад будущего опыта требует нового вызова Connector с физическим BL этой WL; таблица используется для маршрутизации входных спайков, не вместо измерения.
Маска и масштабы фиксируются до нового heldout. Actual CIFAR, SET/RESET и патч драйвера не входят в предложение.
