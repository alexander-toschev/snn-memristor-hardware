## Что добавляют пять адресов

Supported вне candidate: WL3/BL12, WL3/BL13, WL3/BL31, WL5/BL15, WL7/BL15.

**Они не увеличивают исторический геометрический потолок выше 47 коэффициентов текущего маршрута.** Однако они увеличивают максимум, построенный только из исторически поддержанных адресов внутри пула 118, **с 46 до 47**. Причина — пара WL2/WL3: внутри пула9/8 supported, во всём H15 —9/11. Достаточно одного из WL3/BL12, WL3/BL13, WL3/BL31, чтобы снять нехватку одной отрицательной ноги; два других остаются запасом. Выбор конкретной пары по singleton-карте не заменяет её измерение.

WL5/BL15 добавляет запас на уже более многочисленной стороне пары WL4/WL5 (11/11 внутри пула →11/12). WL7/BL15 также добавляет запас (13/15 →13/16). Они не увеличивают одновременную ёмкость при фиксированных парах WL.

Исходный маршрут содержит 94 уникальных ячейки; из них 93 исторически supported. Единственный original-адрес, не прошедший H15 singleton-критерий, — WL3/BL15. Поэтому наличие 47 слотов в файле не означает 47 исторически подтверждённых разностей. Обе ноги singleton-supported у 46/47 фиксированных пар; фактический более строгий H15 contrast-критерий прошли лишь 38/47.

## Граница результата

59 — только комбинаторная ёмкость118 candidates без отбора по исторической пригодности. 101 supported дают 47 пар/94 участвующих ячейки и 7 непарных остатков из-за дисбаланса WL. 96 supported внутри candidate дают 46 пар/92 ячейки и 4 остатка. Ни одно из этих чисел не является новым числом программируемых коэффициентов, одновременно доступных обученных фильтров либо абсолютным максимумом массива 256.

Для максимума охвата полезно документировать пропущенную supported-ногу WL3 как конечную возможность замены/ротации. Увеличить потолок 47 по этой исторической карте при тех же WL-парах нельзя простым добавлением пяти адресов: потребуются новые данные о других состояниях/адресах либо иной reviewed layout. Новая квалификация здесь не выполнялась.
