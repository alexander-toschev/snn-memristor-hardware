16 октября 2026. Отдельный scientific_validator, анализ локальных артефактов.
Аппаратный сбор завершён: представлены все 300 коэффициентов и 2400 выходов
четырёх Conv1-фильтров. **Точность записи обученных весов не подтверждена:**
`physical_weight_quality_pass=false`, quality прошли 5 из 29 микротайлов.
Это завершённый диагностический эксперимент, не успешная квалификация точности
полной CIFAR100-сети и не доказательство максимальной ёмкости всех 256 ячеек.

## Что именно измерено

Для каждой из четырёх пар WL измерены последовательные one-hot вклады через
public MemriBoard Connector. Цифровое сложение новых ADC-вкладов — не
одновременное физическое суммирование всех 32 входов массива. После нулевых
отсчётов применяется заранее зафиксированная матрица C, затем разность
каналов и фиксированный масштаб `alpha_target=1 V/weight`. Fitted alpha
используется лишь как диагностика. Сумма всех 75 taps выполняется до одного
обученного BN[t] и одного шага цифрового LIF на логический t, включая T10/T11.

Обозначая q=(1,-1), измеренный вектор каналов x, получаем вклад
`qᵀ C x / alpha_target`; матрица обучалась на отдельных synthetic-пробах
относительно измеренного H, без подгонки под CIFAR-ответы. Эталон W_eff
вычисляется из свежего H и той же C/gain. Совпадение с ним проверяет
согласованность измерительного оператора с полученными весами, а не
успешное восстановление обученных коэффициентов.

SET завершился как hit для 151 taps, exhausted для 97, overshoot для 52.
Близкие aggregate NRMSE до/после не доказывают отсутствие каждого вида
дрейфа, но не указывают на большой дополнительный aggregate рост ошибки

Восемь наибольших raw weight-residual дают **66.95% общей SSE**. Их negative
legs относятся к WL3/BL8 или WL7/BL8 в разных тайлах: f1 taps 56,48,21,30
и f3 taps 42,54,29,68. Например f1/tap56: target +0.0703613, measured
-0.387470, residual -0.4578313; negative leg WL3/BL8, positive WL2/BL6.
Это воспроизводимая концентрация ошибок по адресам, **не доказательство**
дефекта ячейки, alias в драйвере, неверной полярности или физического
механизма. Для причинного вывода потребуются отдельные ограниченные
контрольные измерения; этот отчёт их не запускает.

## Роль C и проверка N=1

Выбраны 16 identity и 13 diagonal C; matrix selection-pass у 19/29.
Выбранные диагональные коэффициенты лежат в [0.99471874,1.00940079].
RMS изменения веса из-за C составляет 0.00015091, max 0.00120979;
weight RMSE после C 0.07190331 против 0.07193959 без C. Максимальное
singleton-reference изменение 0.00098143 V. Такая коррекция мала по
сравнению с ошибками записи и их не устраняет. Непрошедшие matrix-quality
случаи сохранены в диагностическом результате, а не скрыты.

Реально разделился только исходный блок filter3/parent4: **12+1**, не
предполагавшиеся ранее 13+1. Singleton содержит tap64; reference rank=1
и training rank=1, full C исключена. Выбрана
`diag(1.0055636982747638,1)`, selection-pass=true,
`H=(0.057866,0)ᵀ`. Второй gain=1 — сохранённая конвенция для нулевого
канала, а не идентифицированный параметр. Таким образом аппаратно
упражнена ветка N=1, которую полный adaptive SIM сам не упражнял.

## SIM, покрытие и границы вывода

Сопоставление с adaptive SIM даёт HW−SIM Conv RMSE=0.28914462 и 85/2400
различающихся спайков. SIM−trained Conv RMSE=0.05354526 и 55 спайков;
HW−trained=0.26647667 и 50. Меньшее число несовпадений спайков у HW не
доказывает превосходство платы: пороги LIF нелинейны, ошибка Conv существенно
больше, физические состояния/истории и разбиения различаются. Gain SIM=0.03,
HW=1 — разные фиксированные предварительные масштабы. Их нельзя незаметно
подгонять по CIFAR, чтобы улучшить сравнение.

Union contributing адресов: 118 RESET-probed, 110 хотя бы раз eligible,
105 selected/assigned, 100 SET-attempted. **105 assigned не означает 105
точно записанных ячеек**, одновременное размещение 300 весов или доказанный
максимум массива. Это последовательное использование фиксированного пула
при сохранённых quiet-критериях. Capacity и исторические адреса вне пула
рассматриваются отдельно в
`results/cifar_feedback_reviews/adaptive_hardware_capacity_20261016/`.

Итоговый научный статус: проверена полнота ограниченного аппаратного
Conv1/BN/LIF эксперимента и близость actual к собственным измеренным W_eff;
точность trained W, абсолютный максимум ячеек и accuracy классификатора
не подтверждены. Следующая осмысленная гипотеза — адресно обусловленное
ошибочное программирование/измерение больших residual; причины пока не
разделены. Практическая методика не заявляется научно новой.
