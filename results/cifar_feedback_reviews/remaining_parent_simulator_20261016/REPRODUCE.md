# Проверка импорта завершённого A в черновик B/C

Результат: **65 проверок, 0 ошибок**. Сохранены ровно 280 коэффициентов,
исключены B11+C9, сохранены новые 13 коэффициентов A и происхождение первых 42.
Исторические счётчики: 572402 вызова и 36893 записывающих импульса, без
повторного прибавления baseline. Подмена SHA, simulator→hardware и повреждение
raw отклонены. Исходные файлы при проверках подмены не изменялись.

Из корня checkout, в настроенном окружении из [REPRODUCE.md](../../../REPRODUCE.md):

```sh
python -B -m unittest test_remaining_parent_import -v
```

Сохранить повторный отчёт в **новую** папку:

```sh
python -B test_remaining_parent_import.py --output results/cifar_feedback_reviews/remaining_parent_simulator_recheck
```

Существующий отчёт не перезаписывается. При отсутствии реальных manifest
ASIM или его предков unittest явно выдаёт `SKIP`, а не подтверждение проверки.
Неполные или повреждённые данные при имеющихся manifest приводят к ошибке.

Это offline-проверка импорта, происхождения и счётчиков, а не повторный
численный аудит всех raw и не новый эксперимент. Binding создан только в памяти
для настоящего simulator A55134577; аппаратный parent не выдуман, ветвь реального
неудачного A здесь не проверена. Публичная конфигурация B/C остаётся отключённой,
dispatcher, collector и A не изменены. Плата и native simulator не вызывались.
