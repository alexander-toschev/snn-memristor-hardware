# Групповые маски MVM — без записи

Публичный Connector/converters/INI, WL0/7, три повтора, 0,05 В.
Фиксированные маски: BL0..7;8..15;16..23;24..31;16..31;16..30;31;14;14+16..30.
Для каждой: zero → свежее mode7 R каждой активной ячейки → полный32-вектор
mode10 → zero. **648 вызовов, 0 SET/RESET**, wall600с, raw64MiB.

Guard суммирует max(0,05,nativeDAC→V)/R по всем активным ячейкам;
сумма≤5mA,330I<3,3В, измеренный ADC→V≤4В. Guard не заменяет измерение MVM.
BL14 и mixed идут подряд; сохраняется measured mixed−BL14. Это описательная
разность двух измерений, не доказательство аддитивности или отдельного вклада.
BL31 и группа16..30 позволяют не приписать отклик всей верхней половине,
если отвечает только31. Положительный групповой отклик сам по себе не
доказывает перестановку каналов; нуль не устанавливает конкретный обрыв.

```bash
.venv/bin/python -B experiments/mvm_group_diagnostic_20261022/experiment.py --run-hardware --publish
```

Локально `--dry-run`/`--run-simulator`; результаты под
`results/mvm_group_diagnostic_20261022/<UUID>`. Сохраняются все raw, summary,
HTML, INI, manifest. Публикация после закрытия порта: archive/receipt/summary/HTML,
два secret scans, обычные hooks/LFS. `--publish-session UUID` повторяет только
публикацию. Никаких автоматических новых измерений, приватных вызовов или MNIST.

Отдельная offline трасса: `tools/trace_mvm_driver_offline.py` извлекает только
AST метода private mode_mvm в инертные заглушки. Не импортирует приватный
модуль и не вызывает GPIO/SPI; регистры маршрутизации заглушены. Записывает
байты/CS/sourceSHA, не приватный код. Для повторной попытки использовать новый
output (например `ACTUAL_DRIVER_TRACE_V2.json`), сохранив первый отрицательный.
