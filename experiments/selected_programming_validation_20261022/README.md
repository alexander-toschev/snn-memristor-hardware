# Проверка программируемости 16 выбранных ячеек — 22 октября

Собственный `experiment.py` выполняет фазы A и B через публичный MemriBoard
Connector, штатные конвертеры и INI. Общий строго типизированный сценарий
измерений находится в `experiment_common/programming_validation.py`.
Прямого доступа к драйверу и GPIO нет. Состояние SIM вручную не редактируется.
Нейросеть и идеальное умножение W@x в этом опыте не используются.

Исходная аппаратная карта: `4c8c70ca-f819-4c82-83c8-8fed7f9fe3b0`, 20 октября.
SHA файла карты:
`e452e89b3923873de5138142d9511b689d2d10d5245d2c1222f73d46d446b085`.
Выборка берётся из сохранённого `sample.json` предыдущего сценария чтения,
без импорта его кода. Адреса фиксированы: WL 0 и 7;
BL 2, 3, 6, 10, 11, 12, 14, 15. Проверяются 16 ячеек, не все 256.

Аппаратное чтение 22 октября — сессия `75299d0c-c8dc-4043-b282-e43c15778ac5`:
36 из 40 ячеек выполнили текущие критерии; среди выбранных — 15 из 16.
У ячейки WL7/BL2 стандартное отклонение составило 2,014 ADC при допуске 2 ADC.
Стабильный нулевой выход не означает пригодный вес. Новый опыт проверяет
разрешимый программируемый диапазон и оба направления дифференциального
отклика. Прежняя карта имела диагностический статус; её история не меняется.

## Конечный сценарий

1. Начальное измерение фазы A: по 10 последовательностей
   «ноль → свежее чтение R → сигнал 0,05 В → ноль» на каждой из 16 ячеек.
2. Два цикла R→M→H. R: восемь импульсов RESET с напряжениями
   0,3; 0,6; 0,9; 1,2; 1,5; 2; 2,5; 3 В.
   M: SET на первых четырёх уровнях. H: SET на следующих четырёх уровнях.
   После программирования каждой ячейки выполняется немедленная проверка.
   После обхода группы следуют проверки с задержками 0, 10 и 60 секунд от
   последнего решения об импульсе. В каждой проверке — 10 последовательностей
   чтения. В конце повторно измеряется состояние H всей группы.
3. Оценки A рассчитываются по исходным формулам. Если хотя бы одна из 16 ячеек
   не прошла обязательные требования к диапазону, полноте измерений или
   допуску обеих полярностей, результат — `no_stable_rectangle`.
   Фаза B не начинается, замена адресов не выполняется.
4. При успешной A фаза B проверяет конфигурации plus (H/R), minus (R/H),
   zero (M/M) и checkerboard. Каждая конфигурация программируется заново
   самостоятельными рецептами R+SET. Выполняются 10 чередующихся чтений
   WL0 и WL7, затем повтор через не менее 60 секунд от последнего решения
   об импульсе. M/M не считается нулевым весом автоматически: остаточный
   дифференциальный выход измеряется.
5. Обе signed-ориентации обязательны. Их отказ даёт
   `pair_qualification_failed`. Превышение критериев шума или дрейфа сохраняется
   как диагностическое качество. Пороги не меняются, адреса не переотбираются,
   новых повторов и расширения до 256 ячеек нет. Матрица C не строится.

| Фаза | Число проверок | Максимум вызовов | Максимум импульсов | Ожидания |
|---|---:|---:|---:|---:|
| A | 416 проверок ячейки | 17664 | 512 | ≤360 с |
| B | 64 проверки пары | 6656 | 768 | ≤240 с |
| Всего | | 24320 | 1280 | ≤600 с |

Решение, отклонённое токовым ограничением, не вызывает импульс и сохраняется
в журнале. Общий временной бюджет — 1200 секунд. Ориентир полного A/B:
11–14 минут, без гарантии срока. Невалидные R/ADC и превышение токовых либо
выходных ограничений останавливают опыт без подстановки нулей.
Результаты с ошибкой и отрицательные результаты также сохраняются.

Ток чтения: max(0,05 В, напряжение после штатного DAC→V)/R ≤0,005 А;
предсказанный выход 330I <3,3 В; измеренный выход ≤4 В.
Перед каждым импульсом измеряется свежее R. Для записи requestedV/R
ограничивается 0,04 А при RESET и 0,002 А при SET.
На плату передаётся длительность 0: это штатный интерфейс с неизвестной
фактической длительностью, а не утверждение об отсутствии импульса.
В SIM используется 0,000125 с; эквивалентность аппаратной длительности
не заявляется. RESET изменяет сопротивление; мембранного потенциала LIF
в этом сценарии нет.

Обязательный критерий A:
span = meanH − meanR − 3×hypot(sdH,sdR)/sqrt(10).
Минимальный span двух циклов должен быть ≥max(10 ADC, 5×noise).
В каждом цикле должны быть допущены обе полярности.
Критерии качества: SD≤max(2,0,05×span), drift≤max(3,0,05×span),
различие циклов≤max(4,0,1×span); сдвиг нуля≤max(2,3×SDzero/sqrt(10)).
Обязательный критерий B для обоих направлений:
sign×meanDifference≥max(5 ADC,5×SDdifference).

Эти формулы и рецепты проверяются сравнением с исходными функциями 20 октября.
На сохранённых аппаратных данных также получено точное совпадение оценок
16 ячеек и 8 пар. Проверка подмножества не воспроизводит воздействия на
остальные 240 ячеек и не подтверждает устойчивость всей матрицы.

## Команды

```powershell
.venv-mnist-pilot/Scripts/python.exe -X utf8 -B experiments/selected_programming_validation_20261022/experiment.py --dry-run
.venv-mnist-pilot/Scripts/python.exe -X utf8 -B experiments/selected_programming_validation_20261022/experiment.py --run-simulator
```

На Pi, из корня репозитория:

```bash
.venv/bin/python -B experiments/selected_programming_validation_20261022/experiment.py --run-hardware
```

Результаты: `results/selected_programming_validation_20261022/<UUID>`.
Сохраняются полный raw, manifest, protocol, sample, INI, observations, map
и исходный массив SIM. Блокировка аппаратного доступа и закрытие порта
выполняются штатно, включая завершение через finally.
Приватные драйверы повторно не аттестуются; это явно отражено статусом
`private_runtime_not_independently_reverified`.

и не результат аппаратной проверки.

## Что далее для MNIST

16 ячеек дают только 8 дифференциальных коэффициентов. Это диагностический
этап, а не квалификация исходной раскладки из 200 ячеек на 4 фильтра.
Аппаратная цель остаётся прежней: 64 фильтра по 16 групп, если пригодность
соответствующих адресов будет подтверждена.

Короткий первый MNIST должен использовать свежие аппаратные MVM,
а не точный кэш SIM и не CPU-умножение прочитанных весов. Все 25 измеренных
вкладов должны суммироваться до одного шага LIF. Размещение, объём обучения
и теста, а также стоимость определяются после аппаратных A/B данных.
Этот опыт не выдаёт нейросетевую точность.
