# Адаптивная запись 37 кандидатов

Все воздействия выполняются публичным MemriBoard Connector с репозиторным INI.
Общий алгоритм: `experiment_common/adaptive_programming.py`. CPU выбирает
амплитуду; фактическую проводимость и MVM измеряет MemriBoard.

1. Для каждого адреса RESET/SET staircase 0.3–3 V определяет фактические
   конечные G. Это ограниченное обследование, не физически полный диапазон.
2. Если span > 8 × 2.560355 мкСм, фиксируются цели 20/50/80% диапазона.
3. Два прохода: вверх и вниз, до 64 импульсов на цель. Независимые амплитуды
   SET/RESET увеличиваются при отсутствии реакции и уменьшаются при перескоке.
   Все ограничения тока сохраняются. Физическая длительность неизвестна;
   переданное значение 10 мкс не считается измеренной длительностью платы.
4. Два свежих тройных чтения подтверждают цель после паузы. После остальных
   ячеек выполняется общий readback. Проверяется singleton MVM при двух фонах.
5. Статус programmable требует 6/6 целей и финального попадания. Он ещё не
   квалифицирует дифференциальную пару или группу для MNIST.

Локальная проверка:

```powershell
.venv-mnist-pilot/Scripts/python.exe -B experiments/adaptive_cells37_20261022/experiment.py --run-simulator --fixed
.venv-mnist-pilot/Scripts/python.exe -B experiments/adaptive_cells37_20261022/experiment.py --run-simulator
```

На Raspberry из Git checkout:

```sh
../../.venv/bin/python -B experiments/adaptive_cells37_20261022/experiment.py --run-hardware --publish
```

Единственный foreground-процесс, до 30 минут, 16000 pulse decisions,
180000 native calls; никаких фоновых запусков. Только адреса candidates.json.
Публикация выполняется после close_port и закрытия raw. Повтор публикации
без аппаратных воздействий: `--publish-session UUID`.

SIM: fixed session `38d764bb-ba99-4535-baa6-07f535c951e5` — 106/216 целей,
7/37 ячеек; adaptive `d947aa34-232d-44b3-b7a1-e4b6212999ef` — 211/216,
33/37 ячеек. Одна ячейка не получила целей из-за узкого discovery span.
Оба режима используют одинаковое правило целей, но диапазон измеряется
независимо в каждом прогоне; это сравнение протоколов, не доказательство
тождественных траекторий шума. Импульсов 10077 против 4606. Accuracy не считалась.

После аппаратного обследования: выбрать пары по реальным диапазонам и
проверить signed/group MVM после записи, затем расширять MNIST mapping.
Калибровка и readout адаптируются только на calibration/train/validation;
test не используется для выбора параметров. Предыдущие raw и accuracy
остаются неизменными baseline.

Аппаратная сессия `71a00bab-a33f-4fb2-b459-bfce24ff0bee`: completed,
37/37 адресов,168/216 целей,15 ячеек прошли6/6 и общий readback,
3391 импульс,117.21с. Ещё16 адресов имели два одинаковых целевых уровня,
успешных в обоих направлениях. Их фиксированные границы и середина записаны
в `refined_targets.json` с происхождением; test-метки не используются.

`--refine` программирует только эти16, после чего перечитывает15 ранее
прошедших ячеек без записи. Допуски прежние, соседние интервалы не пересекаются.
Это новые более узкие цели, не исправление старых данных. SIM
`dd4c85f6-8aae-4687-b0d3-8df492185d3d`:16/16 completed,15 программируемых;
hardware-интервалы не обязаны помещаться в диапазон модели симулятора.
