# MemriBoard: recorded cell problems

Static report for all 256 physical addresses. Select an address on the map to see the recorded problems and supporting measurements.

Source: [dfc1cdd79a33ae3b145a7cdd07bac023ca9283ae](https://github.com/alexander-toschev/snn-memristor-hardware/tree/dfc1cdd79a33ae3b145a7cdd07bac023ca9283ae/reports/2026-10-26/cell-problems).

The site contains only the public report. Evidence links point to the source repository.
Rebuild with `python tools/build_cell_problems_pages.py --output <site-directory>` from the research checkout, then commit and push the generated files to `codex/cell-problems-site` with the standard secret-scanning hooks.
