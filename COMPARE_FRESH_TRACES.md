# Прямое HW–SIM сравнение сохранённых выходов

```sh
python -B compare_fresh_traces.py --repo . --first reports/HARDWARE_TRACE --second reports/SIMULATOR_TRACE --output reports/NEW_COMPARISON
```

Оба входа создаются опубликованным `export_fresh_trace.py`. Пути относительны репозиторию; выходная папка новая и не пересекается с входами. Порядок двух входов не важен: разность всегда HW минус native SIM. Работает стандартная библиотека Python, без оборудования, сети и записи в исходные файлы.

Требуется контракт экспорта v2. Маршруты сравниваются по каноническому parsed JSON SHA, а их исходные байтовые SHA сохраняются отдельно. Это учитывает подтверждённое различие CRLF Windows / LF Raspberry, сохраняя строгий отказ при изменении адреса, веса или другого содержимого маршрута. v1 отклоняется с требованием нового экспорта, а не принимается без проверки маршрута. Старые опубликованные каталоги не перезаписывать.

Проверяются SHA и размер CSV, контракт экспортёра/анализатора/аудитора, единицы, source gain, ровно 2400 уникальных упорядоченных ключей filter/case/original_test_index/repeat/t, конечность чисел, порог и hard reset LIF. Fixture, обученные веса, физический план маршрута и протокол должны совпасть. Исходные commits, результаты программирования и C могут различаться. Отсутствующие строки не заменяются нулями, дополнительного fit или rescale нет.

JSON и Markdown содержат RMSE, максимум абсолютной разности и среднюю знаковую разность Conv/BN/V_before/V_after, число несовпадений спайков среди 2400 повторённых и 480 уникальных логических точек, а также метрики по четырём фильтрам. Сравниваются выходы калиброванного измеренного тракта в единицах checkpoint, а не сырые напряжения. Различные gain HW=.25/SIM=.03 не означают равенство физики или шума.

Сравнения каждого прогона с обученным эталоном и W_eff сохраняют самостоятельный смысл; скрипт их не пересчитывает и не выводит из них HW–SIM разность. Полный raw-аудит здесь не повторяется: входные компактные экспорты связывают проверенные manifest/audit/summary. Это не результат полной классификации CIFAR.
