# Причины отказа качества и расхождения LIF

Офлайн-скрипт `diagnose_fresh_fidelity.py` читает завершённую сессию после независимого аудита. Закреплённый `analyze_fresh_stability.py` проверяет manifest, весь инвентарь SHA результатов, входной fixture и связь аудита с протоколом. Повторный численный raw-аудит не выполняется. Никаких вызовов оборудования, подгонки C или изменения весов нет.

```sh
python -B diagnose_fresh_fidelity.py --repo . --session results/SESSION_PATH --audit results/AUDIT_PATH/audit.json --output reports/NEW_PACKAGE/DIAGNOSTICS.json
```

Все пути относительны репозиторию. Выходной файл должен отсутствовать; существующий пакет можно дополнить новым файлом. Максимум 250000 байт, без тихого усечения. Команда печатает SHA и размер, которые следует включить в отдельный список опубликованных файлов; уже существующий PROVENANCE упаковщика автоматически не меняется.

JSON содержит причины качества всех тайлов до и после CIFAR: NRMSE, неопределённость, разрешённый неправильный знак, неразрешённый знак значимой цели. Пороги остаются прежними. Ошибки пары не являются диагнозом отдельной ячейки.

Экспортируются только строки несовпадения спайка с обученным эталоном или W_eff, а также группы, где спайк различается между пятью повторами. Для них сохранены Conv, BN, потенциалы до/после сброса, предыдущий потенциал и знаковое расстояние до порога 1. W_eff построен из post-all калибровки с C и фиксированным gain; это не немедленный own-парный эталон. Отсутствие строки не означает отсутствия иных численных ошибок. Полные trajectories, raw и входные данные не копируются.

```sh
python -B -m unittest test_diagnose_fresh_fidelity -q
```
