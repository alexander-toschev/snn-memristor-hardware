# Компактная публикация карты

`package_fresh_report.py` работает только с сохранённым результатом `analyze_fresh_stability.py`. Он не вызывает Connector, не обращается к сети и ничего не публикует. Нужен Python 3.9 или новее, только стандартная библиотека.

Сначала закончите независимый аудит и научный анализ. Возьмите SHA-256 файла `SCIENCE.json` из проверенного локального результата. Затем выполните одну команду, подставив относительные пути и этот SHA:

```sh
python -B package_fresh_report.py --repo . --science-dir results/PATH_TO_SCIENCE --science-sha256 VERIFIED_SHA256 --output reports/2026-10-16/NEW_PACKAGE --include-png
```

`--include-png` необязателен; при его наличии исходный PNG должен существовать. Папка назначения должна быть новой и не пересекаться с источником. Поддерживаются одна или две сессии в одном SCIENCE. Статус завершения и фактические количества берутся из связанных manifest/audit/SCIENCE; неполная сессия не превращается в завершённую. Неполный результат допускается лишь при согласованных метаданных и успешном независимом аудите; упаковщик сам не создаёт недостающий анализ.

Проверяются закреплённый SHA анализатора, явный SHA SCIENCE, связи с manifest, аудитом, протоколом и исходным commit. REPORT, SVG и CSV сверяются с данными SCIENCE и формулами закреплённого анализатора. PNG связан SHA и ограничениями формата/размера; автоматическая проверка его визуального соответствия SVG не выполняется.

Выход содержит только REPORT, SVG, CSV, необязательный PNG, README и PROVENANCE. Максимум 500000 байт на файл и 950000 байт на пакет; превышение прекращает упаковку до создания папки. Полные raw, SCIENCE, audit, исходные веса и private-файлы не копируются. Raw replay по одному компактному пакету невозможен. Карта отражает наблюдения и не квалифицирует точность весов или исправность ячеек.

Проверка без оборудования:

```sh
python -B -m unittest test_package_fresh_report -q
```
