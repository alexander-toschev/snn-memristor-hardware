# Выбор размера блока STDP перед полным MNIST

Выбран блок **256 изображений**, fresh64 фильтра, 10000 train и 10000 test.
Только локальный MemriBoard Simulator. Физическая плата не использовалась.

| Размер | Измеренные блоки, секунды | Прогноз полного маршрута, часы |
|---|---|---:|
| 32 | 6,157; 6,187; 7,984; 6,172 | 11,09 |
| 64 | Не запускался; экстраполяция по входным маскам | 9,55 |
| 128 | 19,969; 17,937 | 8,35 |
| 256 | 34,359; 34,531 | **7,31** |

Прогноз использует точное количество масок всех 10000 train, верхнюю границу
служебных чтений/записей, наибольшие измеренные времена native call и цифровой
обработки изображения в двух плотных блоках256. Инициализация16групп и конечные
LUT учитываются отдельно. На итоговые CPU features/readout оставлен один час;
предыдущий законченный frozen64 маршрут целиком занимал около30,5мин.
Начальная инвентаризация и изменение нагрузки ПК добавляют неопределённость.
Это прогноз, не гарантия достижения accuracy за указанное время.

Полный запуск ограничен **7ч45мин** с резервом15мин на завершение. При
исчерпании бюджета сохраняется partial/failed, полная accuracy не объявляется.
На группу4фильтра приходится40блоков:39×256 и последний16изображений.

## Что проверено

Четыре native SIM benchmark-сессии завершены. В каждом проверены два блока,
настоящие SET/RESET/readback, три одинаковых прохода MVM до использования
LUT и повторная проверка каждого ответа после цифрового обучения. Test labels
не открывались; accuracy для выбора блока не вычислялась. Новый readout на
128train служил только измерению времени. Все полные веса стартуют заново.

Строгая типизация двух исходников и пять функциональных тестов PASS.
Детальные результаты и расчёт: `SELECTION.json`, `INPUT_FULL_COST.json`.
Сессии сохранены побайтово в Git LFS после проверки обычных и распакованных
журналов на секреты: `results/mnist_block_stdp64_20261021/archives/`.

## Изменение протокола и журналов

Проводимости фиксированы внутри блока. Forward использует только измеренный
native MVM; цифровой target STDP переносится между изображениями, но не
подставляется в forward. После блока выполняются до100 native импульсов,
readback и сброс кеша. Это STDP с отложенной записью, не точное воспроизведение
обновления проводимостей после каждого timestep. Качество предстоит измерить.

Для каждого блока сохраняются проводимости до/после, target, спайки, время,
импульсы и решения guards. Boundary correction учитывается отдельно от
корреляционной plasticity. Подробные низкоуровневые raw сохраняются полностью
для первого блока каждой группы; остальные свёрнуты в счётчики и digest.
Полный raw replay всех вызовов невозможен — SHA не заменяет отсутствующие
данные. Старые журналы не удалены. Это сокращает хранение без изменения
самих операций MemriBoard.

## Запуск

Из корня подготовленного репозитория:

```powershell
.venv-mnist-pilot/Scripts/python.exe -B experiments/mnist_block_stdp64_20261021/experiment.py --run-simulator --block-size 256 --wall-hours 7.75
```

Прежние64,29% относятся к отдельному опыту с готовыми весами. Новая accuracy
появится только после всех16групп, нового readout и оценки10000test.
