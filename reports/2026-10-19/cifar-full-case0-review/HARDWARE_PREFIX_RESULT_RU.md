# Сохранённый аппаратный CIFAR prefix

Локальный независимый replay подтвердил **13 целых этапов: stage0…12**
из исходной аппаратной сессии `f21e608c-059f-4dce-afe0-6edf5c26133c`.
Первый этап для нового сбора — **stage13**, заново с программированием,
калибровкой и всеми позициями. Частичные позиции stage13 не используются.

Проверены3 909 496 impact,18 800 импульсов программирования,1328 коэффициентов
и489 216 вкладов tensor. Это нижняя граница фактических операций прерванной
сессии: неизвестный/непринятый хвост не оценён. Полностью покрыты фильтры0…15;
для фильтров16…19 сохранён только первый тайл32taps. Всего нужны48 этапов,
64 фильтра и4800 коэффициентов; полного предсказания пока нет.

55 из56 gzip-частей прошли CRC/EOF. Часть `part-000055.jsonl.gz`,65558байт,
сохраняется неизменной, но целиком исключена из допуска из-за неожиданного EOF.
Кроме неё не используются828 468 полных строк последующего незавершённого
stage13 из CRC-valid частей. Ни footer, ни scope исходной сессии не исправлены.

Проверены последовательность команд/ответов, native R/ADC и токовые guards,
programming feedback, независимые fit/selection/heldout, C, все784 позиции
каждого этапа и final_basis. На этапах0,2,11 диагностический condition отличается
между платформами; остальные поля, ranks, matrices и выбор C совпали в пределах
исходного допуска. Отдельная reviewed политика исключённого rank-deficient
condition прошла проверку SVD margin16×. Поэтому отчёт честно сохраняет
`strict_numeric_replay=FAIL_condition_only`, а не объявляет PASS старого полного
аудитора. Это численная эквивалентность разрешённого решения, не обход ошибок C.

74 source pins сопоставлены:72 локальных файла и2 приватных файла по явному
root-observed receipt. Private bytes локально отсутствуют; receipt является
записью наблюдения оператора, а не подписанной аттестацией или доказательством
неизменности файла во всё время первоначального опыта. Эти ограничения
сохранены в машинном отчёте.

Артефакты: [PREFIX_AUDIT.json](hardware-prefix-diagnostic/PREFIX_AUDIT.json)
и26 отдельных raw/C payloads с индивидуальными SHA/certificates в той же папке.
Исходная сессия неизменна. Этот результат не утверждает текущую проводимость
старых тайлов и не является полным CIFAR classification/accuracy.

Независимый scientific review actual report и native SIM interruption/resume
qualification остаются отдельными условиями допуска продолжения. Плата в ходе
этого локального аудита не вызывалась.
