## Подтверждённый контракт

| Свойство | Проверенный предел или правило |
|---|---|
| Общее число impact | ≤18 304 |
| Mode7, только `vol=0` | ≤13 472 |
| Mode10 | ≤4 832 |
| SET/RESET | 0; ненулевой mode7 запрещён до I/O |
| Логические восьмиканальные векторы | 604; восемь последовательных ответов, не атомарное измерение |
| Геометрия | Все32 BL и все8 WL; старой маски исключения нет |
| Ненулевые входы | 0,025 / 0,05 / 0,1 В; одно общее напряжение замораживается до fit |
| Прогноз перед вектором | Новое mode7-R каждого активного адреса на всех8 WL |
| Guard-напряжение | `max(requested_v,native_decoded_v)`; округлённые0,024 В не занижают прогноз для запроса0,025 В |
| Ограничения | Суммарный модельный ток≤5 мА, модельный выход<3,3 В, дополнительная эвристика по базису; ADC/ID/транспорт проверяются |
| Неполные данные | Пропущенный WL сохраняется как `None`; нет CPU/нулевой подстановки |

Прогноз тока и запас по базису являются модельными ограничениями, а не
измеренной гарантией физического compliance. Невалидные измерения и ошибки
транспорта останавливают сбор. Пропуски по guard сохраняются с причинами.
Позднее изменение состояния не разрешает менять замороженное напряжение.

Матрица `C8×8` и смещение обучаются только на fit-масках плотностей2/4/8/16,
используя измеренную сумму одиночных откликов того же массива как reference.
Ранг нормированного дизайна с intercept должен быть9, condition≤10⁶,
операторная норма C в исходных ADC-единицах≤10, ridge=0,0001 заранее задан.
При непригодном fit калибровка объявляется недоступной; raw-baseline сохраняется.

Test использует другие ненулевые смешанные маски, поздние одиночные ответы
и полный32-входовый вектор, отсутствующий в fit. Проверочные данные, их нули
и LIF не используются для выбора C, смещения, масштаба или напряжения.
Калибровка применяется только к полностью измеренному вектору8ADC.

В LIF-последовательности после каждой восьмиканальной команды четыре разности WL поступают в один
цифровой шаг LIF: leak0,5, threshold1, hard reset0. Заранее заданы три
диагностических коэффициента10/100/1000 на вольт; публикуются все три,
лучший по test не выбирается. Полное молчание отмечается как неинформативное.

## Границы вывода

- Это проверка аддитивности текущего массива. C не исправляет точность записи
  обученных весов через коэффициенты target/measured и не содержит CIFAR-весов.
- Логические суммы референса допустимы только для сравнения; фактические
  совместные отклики должны каждый раз поступать из нового `impact`.
- Синтетический LIF не является обученным CIFAR BN/LIF или физическим нейроном.
- Native SIM создаёт своё состояние: физические веса SIM и платы не уравнены.
- Конечные R, нулевые скобки и поздние одиночные test-ответы позволяют исследовать
  изменение состояния, но не доказывают причинный механизм дрейфа.
- До CIFAR-записи понадобится новая калибровка именно записанного состояния.

Исправление, сделанное по review до фиксации SHA: guard учитывает максимум
запрошенного и native-декодированного напряжения. Дополнительно заранее
расширен диагностический LIF до трёх фиксированных масштабов: один масштаб
может дать исключительно молчание даже при корректном MVM.
